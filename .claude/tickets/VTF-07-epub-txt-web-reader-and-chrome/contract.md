### `vibetts/reading.py` (new)

```python
STATES = ("idle", "loading", "playing", "paused", "finished", "stopped", "error")
class ReadingError(ValueError)          # bad request -> HTTP 400
class ReadingSession:
    def __init__(self, app)             # app: speak(...), pause(), resume(), stop(), cfg.speech
    def start(self, items: list[dict], start: int = 0, voice: str | None = None, lang: str | None = None,
              speed: float | None = None, source: str = "reader", meta: dict | None = None,
              max_chars: int = 500_000) -> dict            # {"session": str, "count": int}
        # items: [{"text": str, "pause": "sentence"|"paragraph" (default "sentence")}]
        # ReadingError: no items, > 20000 items, total chars > max_chars, start out of range, bad pause/speed
        # RuntimeError: voice model missing (missing_message) -> HTTP 503
        # Session id: new uuid4 hex each start. Speed range 0.5..2.0.
    def seek(self, item: int) -> dict       # same session; ReadingError if no session / out of range
    def pause(self) -> dict ; def resume(self) -> dict ; def stop(self) -> dict
    def status(self) -> dict
    def wait(self, since: int | None, timeout: float) -> dict   # returns at once if since is None or != version
    def notify_paused(self, paused: bool) -> None   # TTSApp.pause/resume call this (tray/hotkey pause too)
```

Status dict (also the HTTP `/api/status` body):

```json
{"version": 7, "session": "hex|null", "source": "reader|extension|null", "meta": {},
 "state": "idle|loading|playing|paused|finished|stopped|error",
 "item": 0, "count": 0, "error": null, "voice": "af_heart|null", "lang": "en|null", "speed": 1.0}
```

`version` increments on every change (state, item, session). `loading` = started, first audio not yet playing.
When another request replaces the session's playback (hotkey read, MCP speak) the state becomes `stopped`.

```python
class LibraryError(ValueError)          # unsupported type / unreadable document -> HTTP 400
BOOK_ID = r"[0-9a-f]{16}"
class Library:
    def __init__(self, folder: Path)    # created on first write
    def add(self, data: bytes, filename: str) -> dict          # summary; same bytes -> existing book
    def list(self) -> list[dict]                               # summaries, most recently opened first
    def get(self, book_id: str) -> dict                        # summary + "toc"; marks opened; KeyError
    def chapter(self, book_id: str, n: int) -> dict            # {"index","title","paragraphs":[str]}; KeyError/IndexError
    def set_position(self, book_id: str, chapter: int, item: int) -> None   # KeyError / ValueError
    def delete(self, book_id: str) -> None                     # KeyError
    def add_path(self, path: str | Path) -> dict               # reads a local file (size limit) then add(); LibraryError
```

## HTTP API (slices 2, 3, 4)

Base `http://127.0.0.1:<port>` (default 7724). JSON bodies (`Content-Type: application/json`) unless noted.
Errors: JSON `{"error": "message"}` with 400 (bad input), 403 (Host/Origin), 404, 405, 411, 413, 415, 503 (voice missing).

| Method & path | Body / query | Response |
|---|---|---|
| `GET /`, `GET /<file>` | | static files from `vibetts/web/` (`/` -> `index.html`) |
| `GET /api/info` | | `{"app":"vibetts","version":str,"api":1}` |
| `GET /api/voices` | | `{voices:[{id,label,engine,languages}], languages:[{code,name}], english, other, language_mode, supertonic_installed}` |
| `POST /api/speak` | `{items:[{text,pause?}], start?, voice?, lang?, speed?, source, meta?}` | `{session, count}` |
| `POST /api/pause` · `/api/resume` · `/api/stop` | `{}` | status |
| `POST /api/seek` | `{item}` | status |
| `GET /api/status` | `?since=<version>&timeout=<0..25>` | status (long-poll) |
| `GET /api/books` | | `{books:[summary]}` |
| `POST /api/books` | raw bytes, `Content-Type: application/octet-stream`, `X-Filename` (URI-encoded) | summary |
| `GET /api/books/{id}` | | summary + toc |
| `GET /api/books/{id}/chapters/{n}` | | `{index,title,paragraphs}` |
| `PUT /api/books/{id}/position` | `{chapter,item}` | `{ok:true}` |
| `DELETE /api/books/{id}` | | `{ok:true}` |
| `POST /api/open` | `{path}` (local file) | summary + `"url"` (`http://127.0.0.1:<port>/#/book/<id>`); the app also opens that URL in the default browser |

`voice`/`lang` omitted or `null` = "Auto (as configured)". `speed` omitted = configured speed.

Security: `Host` must be `127.0.0.1:<port>` or `localhost:<port>` (else 403). If `Origin` is present it must be
`http://127.0.0.1:<port>`, `http://localhost:<port>` or `chrome-extension://<id>` with id in `extension_ids` (else 403).
POST/PUT/DELETE require an allowed `Origin` header, except `POST /api/open`, which also accepts a request with no
`Origin` (a local process such as a second `VibeTTS --open` launch; browsers always send `Origin` on cross-site POSTs). No CORS headers, no OPTIONS handler (405).
Never log text content, only lengths/counts.

## Web reader routes (slice 3)

The reader is a single page using hash routes: `#/` (library) and `#/book/<id>` (open that book at its saved
position). `/api/open` and `--open` link to `#/book/<id>`, so the page must handle that route on load.
