# Changelog: VTF-03 OmniVoice as a first-class engine

## 2026-10-15: in-app OmniVoice install, English and Croatian, OmniVoice tab

**Outcome:** OmniVoice installs from Settings, converting the official weights on the user's machine with no PyTorch and no hosting. It reads any text (English and Croatian), and Kokoro becomes one of two engines. Voices are made and managed in a new OmniVoice tab. All changes are uncommitted on branch `VTF-03_omnivoice-engine-ui`, which was cut from `VTF-02_croatian-omnivoice-tts` @ `1fc3115`.

### Files
- `vibetts/omnivoice_setup.py` (new): the installer.
  - Pinned HF `resolve` URLs with size checks, file-level resume, cancel and overall-byte progress.
  - A numpy safetensors reader and an int4 MatMulNBits quantizer that matches ORT bit for bit.
  - A streaming converter guided by `llm_weight_map.json`.
  - It writes the manifest, deletes the cache and creates the `default` preset with seed 0.
  - Also `status`, `uninstall(keep_voices)`, `DOWNLOAD_BYTES`, and a CLI (`install|status|uninstall`, with `--from` for local files).
- `vibetts/data/omnivoice/llm_bidir_int4.onnx` (graph only, 1.2 MB) and `llm_weight_map.json` (new; generated by `build_omnivoice.py --export-graph`).
- `vibetts/model_setup.py`: `download(..., url=)` takes a full URL; Kokoro behaviour is unchanged.
- `scripts/build_omnivoice.py`: the default path delegates to the installer; `--export-graph` is the torch developer path. `scripts/omnivoice-build-requirements.txt` is updated.
- `vibetts/omnivoice.py`:
  - `omni:<name>` ids, with legacy `omni_hr` accepted.
  - `synth(..., lang=)` sets the language token (default `en`).
  - The preset `.json` stores `lang`; `preset_info` and `list_preset_info` are new.
  - `say --lang` on the CLI.
- `vibetts/config.py`, `config.example.toml`:
  - `engine` (default kokoro), `omni_voice`, and `croatian_voice` (where "" means the same as the OmniVoice voice).
  - Old omni voices and ids are migrated.
- `vibetts/tts.py`: `Engine.synth(..., lang=None)` and `SpeakRequest.lang`; the id helpers accept both forms.
- `vibetts/textprep.py`: `prepare(lang=, long_chunks=)`. Long chunks now apply to every OmniVoice request.
- `vibetts/app.py`:
  - Routing table: Croatian text goes to OmniVoice with `hr`. Other text goes to the engine's voice, with `en` for OmniVoice. If OmniVoice is not installed, requests fall back to Kokoro.
  - `EngineHolder.get(voice=)` and `unload_omni`.
  - Install, uninstall and status hooks; preset play; tray engine switching.
- `vibetts/settings_ui.py`:
  - Tabs General | Voice | Kokoro | OmniVoice | About.
  - Voice tab: engine radio, a voice combo per engine, and a Croatian text group.
  - Kokoro tab: the existing model panel.
  - OmniVoice tab, which scrolls:
    - install section (status, cloning checkbox, Install/Cancel/Uninstall, progress);
    - quality steps;
    - Voices list (Play sample / Use as OmniVoice voice / Use for Croatian / Delete);
    - inline `VoiceCreator` (description with sample language, or recording).
  - The modal Add voice dialog was removed.
- `vibetts/tray.py`: an Engine submenu (OmniVoice greyed out until installed) and an "OmniVoice" voice group. Picking a voice switches the engine.
- `packaging/VibeTTS.spec`: bundles `vibetts/data/omnivoice` and adds the hidden import `vibetts.omnivoice_setup`.
- `README.md`: install from Settings, English/Croatian routing, the OmniVoice tab, and a developer section.
- Tests: new `tests/test_omnivoice_setup.py`, plus updates to `test_model_setup`, `test_omnivoice`, `test_app`, `test_config`, `test_settings_ui`, `test_textprep` and `test_tts`.

### Deviations
- The weight map has 253 tensors (196 int4, 57 copied). The 56 tiny q/k-norm weights are embedded in the graph file, as ORT exports them.
- Download progress reports overall bytes across all files. Resume is per file, with no HTTP Range resume.
- The settings hook `croatian_voices` was renamed to `omni_voices`. Hooks `omni_voice_info` and `play_preset` were added.
- When OmniVoice is installed without cloning, the Install button becomes "Add voice cloning", which runs the idempotent install again.
- Orchestrator: the download-size text was corrected to 2.9 GB, or 3.5 GB with cloning.

### Verification
- `.venv\Scripts\python -m pytest -q`: 218 passed, 1 skipped (the ORT quantizer comparison needs `onnx`; it passes in the torch venv).
- The numpy-converted `.data` is byte-identical (`cmp`) to the torch-built one. A local-files install took 18 s, and the converted model reads Croatian at the same RTF as the reference.
- Real HTTP downloads of two small pinned files (community and k2-fsa) succeeded.
- English ASR word match: `omni:default` 0.96, English-designed preset 0.98, Croatian-designed 0.97. Croatian keeps the Croatian-sample default (0.80 vs 0.65).
- `scripts\build.ps1`: the build succeeded with the graph and map bundled. On a copy of the exe with models and `engine="omnivoice"`, `--say` gave English at 1.6x and Croatian at 1.3x real time.
- **Not run:**
  - Install from the built exe's UI, which needs the full 2.9-3.5 GB download (`dist\VibeTTS` is left without OmniVoice for this test);
  - a manual walk through the tabs and tray;
  - listening (samples are in `.claude/temp/vtf03/listen/`).

### Limitations
- The first install downloads 2.85 GB, or 3.50 GB with cloning, from huggingface.co. The weights are CC-BY-NC.
- OmniVoice is about 1.3-2x faster than real time on this 16-core CPU; slower machines may pause between chunks.

**Commit status:** uncommitted.
